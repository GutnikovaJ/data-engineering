Подтверждённая покупка — заказ со статусом paid и хотя бы одной успешной
оплатой без возврата. Возврат — успешная операция с отрицательной суммой.
Выручка считается по order_amount, а не по платежам: повторное списание
не увеличивает стоимость покупки. Первую покупку определяем по ordered_at,
при равенстве времени — по order_id.

# Интернет-магазин: аналитическая звезда
PostgreSQL → loader → Greenplum raw → staging → intermediate → marts.
Staging сохраняет зернистость источников, intermediate сворачивает платежи
и разворачивает дерево категорий, marts содержит два факта и три измерения.
Тестовые заказы исключены из обоих фактов. Измерение клиентов включает всех клиентов.
Заказ 113 имеет двойное списание: тест переплаты выдаёт WARN, данные сохранены.
